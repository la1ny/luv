# Для самой любимой ♡

Нежный адаптивный романтический сайт-подарок. Проект работает как обычный статический сайт: сборка и установка библиотек не нужны.

## Как открыть

1. Распакуй архив в отдельную папку.
2. Открой `index.html` в современном браузере. Для максимально корректной работы локальных ресурсов можно запустить простой сервер из этой папки:
   - Python: `python -m http.server 8000`
   - затем открой `http://localhost:8000`
3. Весь интерфейс и все основные интерактивные элементы работают без сторонних библиотек. Интернет нужен только для загрузки необязательных веб-шрифтов; есть запасные системные шрифты.

## Как персонализировать

Открой `config.js` и измени:

- `myName` — подпись от тебя;
- `secretMessage` — секретное сообщение;
- `letter` — текст письма;
- `reasons` — список причин (можно добавлять сколько угодно);
- `photos` — пути к фото и подписи;
- `musicPath` — путь к аудио.

Поля `girlfriendName`, `meetingDate` и `anniversaryDate` оставлены для будущей персонализации. Пока даты не заданы, счётчик дней не показывается и ложные даты не создаются.

## Как добавить фотографии

1. Скопируй свои фотографии в `assets/photos/`, например `photo-us-1.jpg`.
2. В `config.js` в массиве `photos` замени `src: "assets/photos/photo-1.svg"` на `src: "assets/photos/photo-us-1.jpg"`.
3. Измени `caption` (подпись в модальном окне) и `label` (короткий текст на карточке).
4. Не нужно менять `app.js`: галерея строится автоматически из настроек.

В проекте лежат шесть красивых SVG-заглушек, которые можно заменить реальными снимками.

## Как добавить музыку

1. Положи MP3 в `assets/music/` и назови его `our-song.mp3`.
2. В `config.js` укажи `musicPath: "assets/music/our-song.mp3"`.
3. Музыка стартует только после нажатия кнопки «Музыка» — автоматического воспроизведения нет. Если файл отсутствует, сайт продолжает работать и покажет подсказку.

## Что реализовано

- экран-сюрприз с переходом к сайту;
- плавные появления секций и сердечки;
- 24 причины без повторения до сброса;
- адаптивная галерея и модальное окно;
- анимированный конверт и любовное письмо;
- четыре интерактивных сюрприза и секретное окно;
- интерактивное сердечко;
- ночная вселенная со звёздами и созвездием;
- финальное сообщение и сброс состояния сайта;
- переключатель фоновой музыки;
- клавиша Escape закрывает модальные окна;
- поддержка `prefers-reduced-motion`.

## Публикация

Для публикации можно загрузить папку на GitHub Pages, Netlify или Cloudflare Pages. Так как проект статический, сборка не требуется. Перед публикацией замени заглушки на свои фотографии и проверь, что у тебя есть право публиковать выбранную музыку и снимки.
